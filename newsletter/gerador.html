Como publicar no Brevo
  1. Preencha os campos abaixo — o e-mail ao lado se atualiza sozinho.
  2. Suba as fotos novas para a pasta assets/ do site (peça aqui no chat que eu subo). Nos campos de imagem, basta escrever assets/nome-da-foto.jpg.
  3. Clique em Copiar HTML para o Brevo.
  4. No Brevo: Campanhas → Criar uma campanha de e-mail → Criação → Cole seu código → cole tudo → Salvar.
  5. Envie um teste para você antes de disparar. Plano gratuito: 300 e-mails/dia — um bloco por dia.
  6. Guarde seu texto com Conteúdo (salvar/abrir): copie o código do conteúdo e cole numa nota; para reabrir depois, cole de volta.
